# 열화상 카메라 얼굴 인식 및 ROI 타겟팅 개선 방안

## 현재 구현 방식

### 1. 얼굴 감지 (Face Detection)

**방식**: 임계값 기반 연결 컴포넌트 분석
- 임계값: `max(환경온도 + 0.5°C, 65번째 percentile)`
- 형태학적 연산으로 노이즈 제거
- 스코어링으로 최적 얼굴 후보 선택
- 온도 패턴 검증 (이마-하단 온도 차이, 온도 분산)

**단점**:
- 고정 비율 기반 ROI 위치 계산
- 얼굴 각도/자세 변화에 취약
- 주변 열원 오인식 가능

### 2. ROI 타겟팅 (이마, 코, 볼)

**현재 방식**: 고정 비율 기반
```python
forehead: (x + 0.25*w, y + 0.05*h, 0.5*w, 0.22*h)
l_cheek:  (x + 0.05*w, y + 0.45*h, 0.28*w, 0.28*h)
r_cheek:  (x + 0.67*w, y + 0.45*h, 0.28*w, 0.28*h)
nose:     (x + 0.40*w, y + 0.40*h, 0.20*w, 0.22*h)
```

**개선 필요 사항**:
- 얼굴 각도 변화 대응 부족
- 온도 분포 기반 동적 조정 제한적
- 얼굴 랜드마크 기반 정확한 위치 지정 없음

### 3. 온도 분포 기반 동적 ROI 조정 강화

**현재**: 기본적인 온도 중심 계산
**개선**: 각 ROI별 특화된 온도 패턴 분석

**이마 (Forehead)**:
- 얼굴 상단 1/3 영역에서 가장 뜨거운 부분
- 온도가 30°C 이상인 영역 중심
- 대칭성 체크 (좌우 대칭)

**코 (Nose)**:
- 얼굴 중앙, 이마와 입 사이
- 온도가 상대적으로 낮은 영역 (호흡으로 인한 냉각)
- 세로로 긴 형태

**볼 (Cheeks)**:
- 얼굴 좌우 측면
- 온도가 이마보다 낮지만 코보다 높음
- 대칭성 체크 (좌우 유사 온도)

**구현 예시**:
```python
def _find_forehead_roi(self, frame, bbox):
    """온도 분포 기반 이마 ROI 찾기"""
    x, y, w, h = bbox
    top_region = frame[y:y+int(h*0.4), x:x+w]  # 상단 40%
    
    # 가장 뜨거운 영역 찾기
    hot_mask = top_region > np.percentile(top_region, 70)
    if np.sum(hot_mask) > 0:
        # 핫 픽셀들의 중심 계산
        y_coords, x_coords = np.where(hot_mask)
        center_x = int(np.mean(x_coords)) + x
        center_y = int(np.mean(y_coords)) + y
        
        # ROI 크기 조정
        roi_w = int(w * 0.4)
        roi_h = int(h * 0.25)
        return (center_x - roi_w//2, center_y, roi_w, roi_h)
    return None
```
